# 已撤销方向：批量内容卡工作台（历史记录）

用户已明确纠正：需要现有聊天图批量导出，而非内容卡。下文仅保留历史测试记录，不代表当前功能。卡片生成代码已移除，当前实现见 `batch-chat-20260910.md`。

## 范围

- 顶部批量创作入口；保留现有聊天、朋友圈及场景工具。
- 多段文案（独立一行 `---` 分隔）→ 首行标题、其余正文 → 3 种内容卡模板。
- 每批最多 50 张，1080×1440 PNG；逐张预览、编辑、模板选择、勾选。
- 单线程串行生成；停止后续任务、失败重试、已完成图片 ZIP 下载。
- 浏览器 Canvas 本地生成，324×432 缩略图预览，原图串行编码后释放画布。
- 不包含 Excel/CSV 导入、多尺寸、正式支付 UI 或新套餐。

## 额度与失败语义

- 每张图使用原有一次导出额度，不按 ZIP 次数计费；不新设付费门槛。
- 渲染/编码失败不发出扣减；先生成 PNG，再请求 `/quota/consume`。
- 每个工作项固定 UUID；网络失败后重试复用，依赖后端既有 action_id 幂等。
- 发出额度确认后锁定内容/模板，避免同一 action_id 导出不同内容。
- 扣减不确定时停止队列，不继续产生更多不确定请求；请以原账号重试。
- 成功图片缓存于本页。重新打包下载不扣减；下载落盘由浏览器控制，不宣称能验证用户已保存文件。
- 取消不撤销已经在进行中的扣减；该张完成并缓存后停止。
- 游客沿用现有本地每日 10 次逻辑，非服务端强防刷机制。
- 不支持刷新后的任务恢复。本页明确提示关闭/刷新会丢失工作，已有工作触发离开提醒。切换工具不会卸载批量工作台。

## 埋点

- 后端 `product-events.mjs` 增加 batch 枚举白名单，并测试拒绝私密正文属性。
- 不上报卡片文案、文件名或生成图像。
- 后端变更尚未部署，因此线上旧服务不能接收新的 batch 枚举。
