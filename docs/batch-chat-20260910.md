# 批量聊天截图 — 当前功能与历史验收

## 当前范围

- 移除无关的知识卡、公告卡等模板，保留队列、固定动作编号和 ZIP 打包。
- 多组聊天文本支持不同长度的独立短横线、Markdown 标题分组；内置模板 Prompt。支持原有消息解析器的时间、语音、图片等格式。
- 同名角色继承现有编辑器头像，手机/气泡/背景设置复制为独立快照。
- 只有输入框一个来源：“添加到批量队列”追加输入文本，不覆盖已有队列。不再提供“加入当前编辑器的聊天”按钮。
- 逐组角色/头像/手机设置及文本编辑，标准顶部一屏与完整长截图两种模式。
- 文本修改后必须更新预览，未应用修改不允许扣额度后输出旧内容。
- 共用 `PhonePreview` 以及从原 App 提取的 `captureChatPhone`，不再独立绘制另一种图。
- 每批最多50组，每组文本导入不超过150条/10000字；长图高度上限16000像素，超限在扣额前报错。
- 仍仅本页暂存，尚未支持刷新恢复。朋友圈和其他现有场景的批量模式尚未接入。

## 当前发布回归

- `scripts/batch-export-smoke.mjs`：一次操作完成生成及 ZIP 下载；重复下载不扣次；部分失败只对新成功项扣次。
- 实际 ZIP 解包：短对话为 1125×2436 完整手机图；测试长对话为 1125×7819，宽度一致。
- `scripts/account-switch-smoke.mjs`：批量中切换账号停止后续扣次；旧响应不会覆盖新账号额度。
- `scripts/export-log-smoke.mjs`：所有工具的全局导出记录、筛选、分页、存储失败提示。
- 批量任务仍只在当前页面暂存，刷新前应下载；导出日志不备份图片或工程。
