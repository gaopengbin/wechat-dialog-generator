# WeChat Dialog Generator 微信聊天记录生成器

> 在线生成微信聊天及相关场景的模拟截图，支持文字、图片、红包、转账、语音等消息类型。聊天内容与图片在浏览器本地处理；账户、额度与支付宝订单由服务端管理。

## ✨ 功能特性

- **多种消息类型** — 文字、图片、红包、转账、语音、时间节点
- **手动添加消息** — 可视化编辑器，逐条添加任意类型消息
- **批量导入** — 支持 Markdown / 纯文本格式批量导入聊天记录
- **AI 模板 Prompt** — 复制提示词到豆包 / ChatGPT 等 AI，再导入返回的聊天文本；站内不直接调用 AI
- **独立工作页** — 聊天、批量聊天图、朋友圈、支付与转账、红包、个人资料和群信息各有编辑与预览区
- **批量聊天图** — 多组对话分别调整角色与样式，一次操作导出 ZIP；重复下载已完成图片不再扣次
- **全局导出日志** — 在当前浏览器统一查看、搜索和筛选各工具的导出记录
- **账户与套餐** — 邮箱注册验证、额度与奖励明细；账户内可选择支付宝次数包、日卡、月卡和年卡
- **更新公告** — 新公告首次提示，关闭后可从顶部「公告」重新查看
- **自定义头像** — 为每个用户上传自定义头像
- **设为自己** — 任意用户可标记为"自己"，消息自动切换左右方向
- **外观设置** — 自定义气泡颜色、联系人名称、时间、信号、电量等
- **高清截图** — 一键导出 1125×2436 高清 PNG 图片
- **长截图** — 支持完整聊天记录长图导出
- **复制到剪贴板** — 截图直接复制，方便粘贴分享
- **图片本地上传** — 图片消息支持点击上传本地图片
- **本地创作** — 聊天草稿与导出日志保存在当前浏览器；批量队列仅在当前页面暂存，刷新前请下载

站点上报页面、工具、导出、分享及账户流程的操作事件，用于改进产品，不在这些事件中上传聊天正文、头像或生成图片。注册、登录、额度与支付请求另由账户服务处理，并非匿名离线功能。分享模板链接可能包含用户主动分享的模板信息，发送前请确认内容。

## 📖 使用方法

### 方式一：文本导入

进入「聊天生成器」的内容导入区，在文本框中粘贴聊天记录，支持以下格式：

```
**【3月1日 14:32】**

**张三**：你好，在忙不？
**李四**：不忙，怎么了？
**张三**：[图片]
**李四**：[红包]恭喜发财
**张三**：[转账]200:饭钱
**李四**：[语音]5
```

### 方式二：手动添加

导入用户后，通过「添加消息」面板逐条添加消息，支持选择发送人和消息类型。

### 方式三：AI 生成

展开「用豆包 / AI 生成聊天记录」面板，复制 Prompt 发给 AI，将返回内容粘贴导入即可。

### 批量导出与导出日志

进入「批量聊天图」，可先用「模板 Prompt」准备多组文本，以独立一行 `---` 或 Markdown 标题分组。粘贴后点击「添加到批量队列」，在编辑队列中调整聊天内容、头像与角色、手机与聊天设置，再确认额度并导出 ZIP。每批最多 50 组；修改文本后先更新预览。

「导出日志」汇总当前浏览器从此版本开始的记录，不是图片备份或工程恢复入口。「已发起下载」不代表文件已保存到磁盘，实际文件请查看浏览器下载列表。批量队列刷新后不能恢复。

### 账户与支付宝充值

首次使用账户功能请先通过邮箱验证码注册，已有账户用邮箱和密码登录。打开账户面板的「充值 / 选套餐」查看当前可购买套餐；购买需要已验证邮箱。价格、优惠截止时间及可售状态以服务端返回的页面内容为准。

确认购买后会尝试打开支付宝收银台；若被浏览器拦截，可点击备用链接。付款后回到工具箱「查询到账」，不要重复下单。会员不自动续费；微信支付暂不支持。

## 🚀 本地开发

```bash
# 克隆仓库
git clone https://github.com/gaopengbin/wechat-dialog-generator.git
cd wechat-dialog-generator

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 单元测试与静态检查
npm test
npm run lint
```

本仓库是前端。开发环境默认账户 API 为 `http://127.0.0.1:9092/platform-api/v1`；需要运行匹配的后端，或在未提交的 `.env.development.local` 中设置 `VITE_ACCOUNT_API_ENDPOINT` 指向自己的开发服务。不要把密钥放入 `VITE_*` 变量，它们会进入前端构建。不要用生产账户做会发送验证码、扣减额度或创建支付订单的自动化测试。

生产站点已配置默认账户与事件端点；自托管时可分别设置 `VITE_ACCOUNT_API_ENDPOINT`、`VITE_PRODUCT_ANALYTICS_ENDPOINT`。仅启动前端不能提供邮箱验证和真实充值能力。

实现与验收记录：[批量聊天图](./docs/batch-chat-20260910.md)、[工作页布局](./docs/workspace-layout.md)、[组件说明](./docs/workspace-components.md)、[已撤销方案的历史记录](./docs/batch-studio-20260910.md)。版本变化见 [更新日志](./CHANGELOG.md)。

## 📝 消息格式参考

| 类型 | 格式 | 示例 |
|------|------|------|
| 文字 | `**用户名**：内容` | `**张三**：你好` |
| 图片 | `**用户名**：[图片]` 或 `**用户名**：[图片]URL` | `**张三**：[图片]` |
| 红包 | `**用户名**：[红包]备注` | `**张三**：[红包]恭喜发财` |
| 转账 | `**用户名**：[转账]金额:备注` | `**张三**：[转账]200:饭钱` |
| 语音 | `**用户名**：[语音]秒数` | `**张三**：[语音]5` |
| 时间 | `**【时间】**` | `**【3月1日 14:32】**` |
